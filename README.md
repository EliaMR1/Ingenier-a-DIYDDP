# Diseña tu futuro — Ingeniería en Diseño Industrial y Desarrollo de Productos

Proyecto académico de 2.º de Bachillerato (Informática). Sitio web de cuatro páginas sobre el grado impartido por la Universitat Politècnica de València (UPV), campus de Vera (València).

## Estructura

```text

    ├── portada.svg

```

## Ver la web en local

Abre `index.html` en un navegador. Para probarla como un sitio web, puedes usar la extensión Live Server de Visual Studio Code.

## Publicar en GitHub Pages

1. Crea un repositorio público, por ejemplo `mi-futuro-diseno-industrial`.
2. Sube el contenido de esta carpeta directamente a la raíz del repositorio.
3. Comprueba que `index.html` está en la raíz y que se han subido también `img/`, `style.css` y `script.js`.
4. En GitHub, abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`. Guarda.
6. Espera a que termine el despliegue y abre la URL que proporciona GitHub Pages.
7. Comprueba las cuatro páginas en ordenador y móvil.

## Commits sugeridos

- `Crea estructura inicial del sitio`
- `Añade portada y navegación principal`
- `Desarrolla página del plan de estudios`
- `Añade información del campus y centro`
- `Completa salidas profesionales y fuentes`
- `Mejora diseño responsive y accesibilidad`

## Antes de entregar

- Sustituye `[ESCRIBE TU NOMBRE]` por tu nombre en los cuatro pies de página.
- Escribe personalmente los tres apartados «Mi opinión» de las páginas secundarias. Deben tener al menos cuatro líneas cada uno y no deben ser redactados por IA.
- Revisa los datos y los enlaces oficiales.
- Haz al menos cuatro commits reales con mensajes claros.
- Comprueba el sitio publicado en móvil y ordenador.
- Conserva el registro de prompts y explica en la defensa oral qué has cambiado y por qué.
