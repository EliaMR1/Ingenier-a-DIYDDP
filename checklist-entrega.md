# Checklist antes de entregar

## Contenido
- [ ] Hay cuatro páginas: inicio, estudios, centro y salidas.
- [ ] El reto de nota de corte y plan de estudios está cumplido.
- [ ] Cada página secundaria tiene «Mi opinión» escrito por mí, con al menos cuatro líneas.
- [ ] Los datos están comprobados y las fuentes aparecen enlazadas.

## HTML y CSS
- [ ] Todas las páginas usan `header`, `nav`, `main` y `footer`.
- [ ] El menú común funciona desde las cuatro páginas.
- [ ] Cada página contiene al menos una imagen local de `img/` con `alt`.
- [ ] Hay al menos una lista y una tabla en el conjunto del sitio.
- [ ] Las cuatro páginas enlazan al mismo `style.css`.
- [ ] No hay estilos incrustados en los HTML.
- [ ] El sitio se ve bien en móvil y ordenador.

## GitHub
- [ ] Repositorio público con `index.html` en la raíz.
- [ ] Al menos cuatro commits con mensajes descriptivos.
- [ ] GitHub Pages está publicado desde `main` y `/(root)`.
- [ ] La URL publicada abre las cuatro páginas y muestra las imágenes.

## Uso de IA y defensa
- [ ] He documentado seis o más prompts reales.
- [ ] He explicado una mejora y un error/riesgo detectado.
- [ ] Puedo explicar una línea de HTML, una regla CSS y una ruta relativa.
- [ ] Puedo justificar las fuentes de los datos.
- [ ] He sustituido el marcador de autor por mi nombre.
